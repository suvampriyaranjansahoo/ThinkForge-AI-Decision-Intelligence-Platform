# XAI-FUNGI codebook (real reference material)

Source: XAI-FUNGI: Dataset from the user study on comprehensibility of XAI
algorithms. Bobek, Korycińska, Krakowska, Mozolewski, Rak, Zych, Wójcik,
Nalepa. Jagiellonian University.
DOI: 10.5281/zenodo.15222484
License: CC-BY-4.0 (reuse permitted with attribution)
Retrieved: 2026-09-05 via direct fetch of CODEBOOK.csv from the Zenodo record.

This is the REAL thematic-analysis codebook the original researchers built
from 39 coded interview transcripts (MAXQDA). It is genuine research
material, not generated.

## What this file is useful for
Use these codes as the real `themes` vocabulary when building
`case_bank.json` cases sourced from this study, instead of placeholder
theme names.

## What this file does NOT give you
The actual transcript TEXT (`TRANSCRIPTS.zip` on the Zenodo record) is not
included here — it requires downloading and unzipping the archive, which
needs to be done locally by a human with access to that file. Once you have
it, paste the real (already-anonymized) participant text into each case's
`input.prompt`, and tag it with the matching code(s) from this file as the
real `themes` value.
