# Frontend Feature Architecture Contract

Target decomposition for the current application shell:

- decisions: decision lifecycle and health
- evidence: evidence ingestion, provenance, contradictions
- assumptions: assumption lifecycle and evidence links
- challenges: adversarial/critical review
- alternatives: option comparison and tradeoffs
- experiments: experiment design and readiness
- outcomes: prediction and observed-outcome capture
- evaluation: annotation, gold, regression and reports
- rag: corpus, retrieval, citations and ablations

The current legacy shell remains compatible; this document defines the bounded feature contracts needed for incremental migration rather than claiming a completed React rewrite.
