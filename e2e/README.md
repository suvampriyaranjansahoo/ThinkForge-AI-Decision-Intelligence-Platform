# Stage 3 browser validation

The production-safe browser validation plan covers:

1. Create/open a decision.
2. Navigate the decision journey.
3. Inspect evidence and reasoning lineage.
4. Review the Opportunity → Solution Tree.
5. Trigger an AI action and verify working/error/retry states.
6. Create an experiment and record an outcome.
7. Verify keyboard navigation and command palette.
8. Verify offline/reconnect behavior.
9. Repeat the critical journey at mobile widths.
10. Capture canonical screenshots for visual regression.

These checks must be executed in a real browser/device runner before being marked PASS. No synthetic PASS result is generated by this repository.
