# Two-minute ThinkForge MVP walkthrough

Use Free Offline Demo Mode. Say that the displayed decisions are demo data before beginning.

1. **Frame (20s):** Open a decision. State the customer, decision, and highest-risk assumption.
2. **Evidence (20s):** Open Evidence. Add or inspect a linked evidence record. Explain that recommendations should not cite unknown records.
3. **Challenge (20s):** Open Challenges. Explain how counterarguments make the uncertainty visible.
4. **Test (20s):** Open Experiment. Point to the success rule, guardrail, and prediction.
5. **Learn (20s):** Open Outcome. Record that a prediction and observed result make the next decision more accountable.
6. **Close (20s):** “This MVP is testing whether a five-step decision record is more useful than a template. I have not claimed user impact yet; the next step is interviews and a paired pilot.”

Record with any screen recorder. Publish only after removing secrets, personal names, and private decision content.
